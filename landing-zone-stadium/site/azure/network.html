Network topology and connectivity

Every landing zone connects to one place: the hub in the connectivity subscription. You can build the hub yourself (hub and spoke) or let Azure Virtual WAN run it. Either way, traffic between spokes, on-premises and the internet is inspected in one place.

Practise in CloudTyke

Hub and spoke works: VNets, subnets, two-way peering (overlapping ranges are rejected), NSGs, route tables with a VirtualAppliance next hop, private DNS zones and links. Azure Virtual Network Manager can build hub-and-spoke or mesh configurations. There are no Azure Firewall, Bastion, VPN, ExpressRoute or Virtual WAN resources, so packets do not really flow. Start with azure-emulator/examples/terraform/landing-zone/.

In the stadium

The hub is the stadium gates and bag check: one way in, everyone checked. Spokes are the stands, joined to the gates by walkways (peering). Bastion is the staff door. Walk it in Chapter 2, Gates, walkways and doors.
