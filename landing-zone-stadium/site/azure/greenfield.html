Start fresh: platform first, then workloads

Contoso is new to Azure. There is nothing to migrate yet, so build the platform landing zone first, then vend landing zones for the first apps. The Azure landing zones accelerator deploys the platform from Bicep or Terraform. You can start small and grow it.
