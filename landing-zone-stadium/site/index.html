What stays, what changes

Same for every event

  • Entry gates: every fan comes in the same way and is checked.
  • Seats and stands: the same standard seating.
  • Security: very important, and the same for every sport.
  • Governance: the same stadium rules for every event.

In the cloud: the platform team builds network, security and governance once.

Changes per event

The pitch and what is set up on it. Football on Saturday, a cricket Test next week, a concert after that.

In the cloud: each app team gets its own landing zone and builds its app there. Swap it fast. The platform does not move.

    Run it for real on CloudTyke

    The Azure version runs on the CloudTyke emulator on your laptop. No subscription, no bill.

    bash landing-zone-stadium/scripts/up.sh
bash landing-zone-stadium/verify.sh

    Then open the dashboard on http://localhost:4310 and find sub-events under Landing Zones.
